# **App Name**: Kailash Kumar Aman - Portfolio

## Core Features:

- Hero Section: Display a hero section with name, location, contact info, and LinkedIn profile.
- About Me: Showcase a brief 'About Me' section summarizing skills and objectives.
- Education: List education details including degree, institution, and grades.
- Internship Experience: Detail internship experiences with company names and project descriptions.
- AI Projects showcase: Projects showcase tool: Use LLM to generate summary or insight from each projects
- Publications: Provide a section for research publications, including titles and publishers.
- Resume Download & Contact: Enable PDF resume download and contact link at the top and bottom.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey professionalism and modernity.
- Background color: Very light gray (#F5F5F5) for a clean and readable layout.
- Accent color: Teal (#009688) to highlight key sections and interactive elements, providing a fresh and engaging feel.
- Font pairing: 'Inter' sans-serif for both headings and body text for a clean, modern, and highly readable design. Its neutral appearance maintains a professional look.
- Modern and responsive layout using Next.js and ShadCN UI components.
- Minimalist icons for skills and contact information.
- Subtle transitions and hover effects to improve user experience.
